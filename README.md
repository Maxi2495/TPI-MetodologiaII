**Integrantes:**
* Maximiliano Nicolás Niemiec
* Paola Pasallo

### Descripción del Sistema Base
Módulo de registro, asignación, seguimiento y reporte de solicitudes y trámites académicos para estudiantes universitarios.

### Entidades Principales
1. `Estudiante`: Alumno solicitante.
2. `Solicitud`: Trámite académico registrado con estado, prioridad y resolución.
3. `Responsable`: Personal docente o no docente asignado para la resolución del caso.

### Operaciones Funcionales Verificables
1. Registrar nueva solicitud académica con validaciones de negocio.
2. Asignar responsable o derivar por área.
3. Cambiar estado de solicitud y asentar resolución.
4. Filtrar solicitudes y generar reporte estadístico básico de gestión.
